# 财务会计（中级）答题练习

打开页面时会自动读取本仓库根目录的 **`questions.md`**，动态生成题目与解析。

## 在线打开

https://haoyi01.github.io/facct-quiz/

## 如何改题

1. 编辑仓库中的 `questions.md`（格式与习题集一致：章节 / 题型 / 答案与解析）
2. Commit 到 `main` 分支
3. 打开答题页，点「重新加载 MD」或强制刷新即可

## 本地预览

需要用本地静态服务器打开（`file://` 下无法 fetch MD），例如：

```bash
npx serve .
```

然后访问提示的地址。
